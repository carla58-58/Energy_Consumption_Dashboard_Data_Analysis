## 1. Project Overview

**Objective:**  
Analyze energy consumption patterns by consumption type, city, building, and time period.

**Key Insights Tracked:**
- Total consumption: **4.06M units**
- Top consumer: **Water** (highest costs)
- City breakdowns, building comparisons
- Monthly/quarterly trends (2016 data)

**Dataset Features:**
- Consumption Type (Water, Electricity, Gas)
- Cities (NYC, LA, etc.)
- Buildings, Date ranges
- Total costs by type/city/building

## 2. Dashboard Features

**Interactive Filters:**
- ✅ Consumption Type slicer (Water/Electricity/Gas)
- ✅ City selector  
- ✅ Building comparisons
- ✅ Date range (monthly/quarterly)

**Key Visualizations:**
- **KPIs**: Total consumption (4.06M), Total cost (70M)
- **Maps**: City-level consumption heatmaps
- **Line charts**: Time trends by consumption type
- **Bar charts**: Top cities/buildings
- **Pie charts**: Consumption type breakdowns
- **Tables**: Detailed quarterly/city data

## 3. Key Findings

- **Water** dominates costs across all cities/buildings
- **Seasonal peaks** visible in line charts
- **NYC/LA** lead consumption
- **Electricity** shows steady usage
- **Building-level** granular insights available
